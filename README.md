# Guia da Mostra Bíblica + Bíblia Sagrada (Boa Terra)

Site estático para hospedar no Netlify (sem build):

- `/` — Guia da Mostra: 5 estandes em ordem, com resumo, galeria, curiosidades e quiz; no final, convite para instalar o app.
- `/biblia/` — Bíblia Sagrada (73 livros), instalável como app (PWA).
- `img/` — fotos opcionais dos estandes (`e{estande}-{0..5}.jpg`; 0 = capa). Veja `img/LEIA-ME.txt`.

Publicação: conecte o repositório ao Netlify, sem comando de build, diretório de publicação `/`.
